# Changelog

Релизы формируются автоматически GitHub Actions при каждом пуше в ветку проекта.
Каждый релиз получает последовательный порядковый номер (`v1`, `v2`, …) и содержит
готовый `CSLHelpdesk.exe` в качестве вложения. Список изменений генерируется из
git-лога с момента предыдущего релиза.

Формат записи ниже — для ручной фиксации значимых изменений между релизами.

## Следующий релиз (незавершённый)
- Исправлено автоопределение AnyDesk/RustDesk ID: AnyDesk ищется по полному пути
  (Program Files, реестр Uninstall, запущенный процесс) и читается из
  `anydesk.conf` (`ad_anywhere_id`), RustDesk — из `RustDesk.toml` в
  `%APPDATA%`/`%LOCALAPPDATA%`/`%PROGRAMDATA%` с корректным разбором одинарных
  кавычек (`id = '123456789'`). Раньше оба поля почти всегда оставались пустыми.
- ID определяются в фоне при запуске (окно не виснет) и подставляются
  автоматически с подписью источника; есть кнопка «Обновить ID». Свежий ID с ПК
  важнее сохранённого.
- Интерфейс: чекбоксы неисправностей — в одну колонку с группировкой
  (раньше две колонки вылезали за край окна), всё окно в прокручиваемой области
  со скроллбаром и колесом мыши, поля ввода растягиваются по ширине окна,
  окно 720px с минимальным размером и DPI-awareness для масштаба 125–150%.

## v1
- Начальная версия клиента заявок CSL Helpdesk.
- Сбор сведений о ПК (CPU/RAM/диски/материнская плата/BIOS/сеть), AnyDesk/RustDesk ID.
- Чекбоксы неисправностей, скриншот, текстовый и голосовой комментарий.

- Развёртывание через GPO (логон-скрипт) + автообновление из GitHub Releases.
